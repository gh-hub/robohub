# 01 — Pan rename (Aim → Pan)

**What to build:** Repurpose the existing Aim Up/Down servo control end-to-end into Pan Left/Right, so the UI matches what the hardware actually does (panning the ultrasonic distance sensor bracket left/right, not tilting a gun barrel up/down). Also rename the underlying IPC method (`setAimAngle` → `setPanAngle`) for full naming consistency, per the user's approval at the tickets checkpoint. No behavior change anywhere — same servo protocol command (`DEVICE_SERVO = 0x02`), same 1-180° bounds, same Fast(10°)/Slow(5°) step speeds, same 400ms hold-repeat interval, same connection gating, same reset-to-90°-on-connect/disconnect/error behavior.

**Blocked by:** None — can start immediately
