# 04 — USB Log panel — connect/stream/disconnect end-to-end

**What to build:** end-to-end data flow from USB serial port to rendered log panel, with explicit user control. Create a new USB-serial-owning module that opens a port at 115200 baud via the shared VID/PID helper from Ticket 1, reads data from it, and closes when requested, with injectable-dependency testability. Create new IPC channels for USB Log connect and disconnect actions, and for pushing log lines. Preload exposes connect/disconnect APIs and a subscription for log lines. Renderer adds a new Connect/Disconnect button pair mirroring the existing Wi-Fi toggle pattern, and wires the USB Log panel to the connection state and data stream. Clicking Connect opens the auto-detected port and streams timestamped lines into the USB Log panel. Clicking Disconnect cleanly closes the port. Closing the app also cleanly closes the port. With real CH340 hardware, this delivers the full connect-stream-disconnect cycle.

**Blocked by:** Ticket 01 (serialport dependency; VID/PID helper), Ticket 02 (shared log-panel infrastructure)
